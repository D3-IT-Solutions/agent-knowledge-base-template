# Policies

Notes about decisions you have already made.

Put a topic here when it answers:

- A rule assistants should follow without re-asking, once it is confirmed
- What always needs your yes first
- How to handle a mistake
- How often these notes get reread

Write the rule the way you would say it to a new teammate. If a lawyer or an accountant still needs to look at it, keep the status at `draft` and put that in **Open questions**.

See [SECURITY.md](../SECURITY.md).

Copy a new topic from [`_templates/topic-template.md`](../_templates/topic-template.md).

`example-what-needs-a-yes-first.md` is a pattern, not your policy. Assistants must not cite it.
