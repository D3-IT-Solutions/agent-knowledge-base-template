# Example: How I like help

> **Example only.** This file shows the shape of a topic. It is not your preference. Assistants must not cite it.

## Summary

A real note tells the next assistant how to work with you. A placeholder is: "Lead with a short answer. Add detail when I ask. Ask before you change a confirmed topic or message someone else."

## Details

A finished note can include:

- How long a reply should be
- Hours when a reminder is welcome
- Decisions that always come back to you

Keep the note to working style. Leave out a home address, a health detail, and any ID number.
