# Personal

Notes about how you like to work with assistants.

Put a topic here when it answers:

- Whether you want a short answer first or full detail
- When reminders are welcome
- What an assistant should ask before it acts
- Words and habits you want reused in every chat

This folder is for working style. It is not a place for a home address, ID numbers, health records, or family documents. See [SECURITY.md](../SECURITY.md).

Copy a new topic from [`_templates/topic-template.md`](../_templates/topic-template.md).

`example-how-i-like-help.md` is a pattern, not your preference. Assistants must not cite it.
