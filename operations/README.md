# Operations

Notes about how work moves.

Put a topic here when it answers:

- How a new request arrives
- The steps from "yes" to "done"
- Who does which step
- A checklist you want followed the same way every time

One workflow per file. Link files when a step has its own write-up.

Leave out passwords for the tools you mention. See [SECURITY.md](../SECURITY.md).

Copy a new topic from [`_templates/topic-template.md`](../_templates/topic-template.md).

`example-how-a-request-moves.md` is a pattern, not a real workflow. Assistants must not cite it.
